Overview
An interactive task management web application created to assist users in organizing their daily activities. It allows users to create, modify, finish, and remove tasks using a straightforward, intuitive user interface.

Key Features
Add new entries directly to the pending tasks list

Mark active tasks as finished/completed

Edit existing task descriptions inline without leaving the view

Remove items from either the pending or completed sections

Distinct, separate lists for active pending tasks and completed items

Real-time live indicators displaying current task counts

Helpful empty-state messaging when lists have no active tasks

Optional creation timestamps and persistent storage using browser localStorage

Technologies Used
HTML5: Semantic document markup

CSS3: Custom styling and visual presentation

Vanilla JavaScript: Interactive functionality, DOM updates, and local storage management

How to Run
Open the project directory using Visual Studio Code (VS Code).

Launch the index.html file inside any modern internet browser.

Begin organizing and managing your daily tasks.
