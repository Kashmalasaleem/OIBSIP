Browser-Based Calculator
Overview
This project is a fully interactive, web-based calculator built as part of the Oasis Infobyte Web Development Internship. It is designed to handle standard mathematical computations efficiently through a clean, responsive, and intuitive user interface.

Key Features
Core Arithmetic: Performs addition, subtraction, multiplication, and division.

Full Numeric Control: Includes a complete 0–9 number pad and decimal point support.

Computation Engine: Computes immediate and sequential mathematical expressions accurately using the equals (=) button.

Editing Controls: Features clear (C) and backspace functionality for easy input correction.

Error Handling: Built-in safeguards to gracefully manage invalid actions, such as division by zero.

Modern UI Design: Styled cleanly using CSS Grid for a structured and organized button layout.

Clean Scripting: Powered by Vanilla JavaScript utilizing modern event listeners, completely avoiding inline onclick attributes.

Secure Logic: Implements custom arithmetic evaluation algorithms entirely without the use of eval().

Technologies Used
HTML5: Semantic document structure

CSS3: Styling and layout via CSS Grid

Vanilla JavaScript: DOM manipulation, event handling, and calculation logic

Getting Started
To run this project locally on your machine, follow these simple steps:

Download or clone this repository to your local computer.

Navigate to the project directory.

Open the index.html file in any modern web browser.

Learning Outcomes & Takeaways
Developing this project provided hands-on experience in structuring semantic HTML, designing modern layouts with CSS Grid, managing DOM events efficiently with JavaScript, handling edge cases and errors, and writing robust conditional logic for numeric computations.
