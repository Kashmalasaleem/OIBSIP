Tribute Page — Abdul Sattar Edhi
Overview
A dedicated tribute website honoring Abdul Sattar Edhi, the legendary Pakistani philanthropist and humanitarian celebrated worldwide for his selfless dedication to helping humanity. The site presents his life journey, selfless service, major milestones, and enduring legacy through a clean, modern, and fully responsive web interface.

Key Features
Introduction: Displays an inspiring overview introducing Abdul Sattar Edhi and his humanitarian mission.

Featured Imagery: Includes a prominent image of Edhi Sahab along with proper attribution and source credits.

Biographical Narrative: Features a detailed biography highlighting his life story and noble contributions to society.

Milestone Timeline: Chronologically details key achievements and major events throughout his humanitarian career.

Inspirational Quote: Highlights one of his memorable, thought-provoking statements in a visually distinct quote section.

Visual Styling: Utilizes appealing typography choices and harmonious background color palettes for enhanced readability.

Responsive Design: Adapts fluidly across various device screens and window sizes for a seamless user experience.

Technologies Used
HTML5: Provides semantic page structure and content layout.

CSS3: Delivers custom visual styling, layout formatting, and responsive styling rules.

Getting Started
To view this project on your local machine:

Download or clone this repository to your computer.

Open the project folder inside Visual Studio Code (VS Code).

Open the index.html file in your preferred web browser.
